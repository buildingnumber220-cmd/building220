خطوات التشغيل

1) الشيت
- ارفع BuildingFund_Template.xlsx على Google Drive ← Open with Google Sheets ← File ← Save as Google Sheets.
- استبدل صفوف "مثال" ببياناتك، واملأ تاب Settings (أمين الصندوق، طريقة الدفع، الإعلان).

2) الـ API
- Extensions ← Apps Script ← امسح الموجود والصق Code.gs ← Save.
- Deploy ← New deployment ← Web app ← Execute as: Me ← Anyone. (للتحديث: Manage deployments ← ✏️ ← New version.)
- شغّل installTrigger مرة واحدة (اختر الدالة من القائمة ثم Run ووافق على صلاحيات الإيميل وDrive): يفعّل تقرير المتأخرين يوم 5 كل شهر، وينشئ مجلدات Drive (الإيصالات/السنة/12 شهر + الفواتير/السنة).

3) الصفحة
- في index.html غيّر PUT_WEB_APP_URL_HERE برابط الـ Web app.
- انشرها مجاناً: Netlify Drop (اسحب المجلد) أو GitHub Pages.
- ضع رابط الصفحة في Summary!J2.

رابط مخصص لساكن: الرابط?apt=1&pin=4829
المتصفح بيفتكر الشقة والرقم السري بعد أول دخول (زر الخروج يمسحهم).

الإيصالات: يرفعها الساكن من صفحته وتتحفظ في Drive باسم الشقة، ويصلك إيميل. الفواتير: ضعها يدوياً في مجلد الفواتير وسجّل رابطها في Expenses!E.
لإظهار تفاصيل المصروفات للسكان: show_expenses = yes في Settings. لمراقبة المحاولات: تاب AccessLog.

تأكيد الإيصال: في تاب Claims راجع الصورة (عمود F) وعدّل المبلغ (D) لو لزم، ثم غيّر الحالة إلى confirmed فتتسجل الدفعة تلقائياً في Payments (ما تكتبهاش يدوي).

المتابعة بعد الإعداد
- وسيلتا الدفع: في Settings (نوع + رقم لكل وسيلة). الصفحة تعرض بطاقة لكل وسيلة بزر نسخ للرقم، وتخفي الفارغة. خانة "بيانات الدفع" صارت ملاحظة اختيارية.
- السكان يرفعون الإيصال مع كتابة المبلغ (الدفع الجزئي مسموح)، ويرون حالة كل إيصال (قيد المراجعة / تم التأكيد / مرفوض مع السبب).
- إيميل الإيصال فيه زرّا تأكيد ورفض (صالحان 14 يوماً ولمرة واحدة، ويفتحان صفحة تطلب الضغط للتنفيذ). ولو رفضت اكتب السبب في Claims!H لو أردت.
- صفحة الصيانة: ارفع maintenance.html بجانب index.html (غيّر PUT_WEB_APP_URL_HERE فيه أيضاً)، واكتب في Settings: اسم مسؤول الصيانة ورمز مسؤول الصيانة (6 خانات على الأقل). أضف المهام في تاب Tasks (المهمة، الموعد، الحالة) وهو يحدّثها من صفحته وتصلك رسالة بكل تحديث.
- جملة اليوم: 149 جملة (آيات وأحاديث وأقوال مأثورة) تظهر في صفحة الساكن لو فعّلت مفتاح جملة اليوم من لوحة الإدارة (أو Settings). ولتعديل جملة عدّلها في QUOTES داخل Code.gs.
- الأمان: شغّل protectSheets مرة (تحذير عند تعديل الخلايا الحساسة)، وsecurityTest عند أي تحديث ثم راجع Execution log، وresetSheets عند الطوارئ فقط (تعيد العناوين والمعادلات والقوائم). النسخة الاحتياطية الأسبوعية (الأحد) تتفعّل بـ installTrigger وتُحفظ في حساب العمارة/نسخ احتياطية.

- لوحة الإدارة (admin.html): ارفعها بجانب index.html (غيّر PUT_WEB_APP_URL_HERE فيها)، واكتب في Settings: رمز الإدارة (8 خانات على الأقل). تعرض رصيد الصندوق وتحصيل المشروع المفتوح والشقق غير المكتملة مع المتبقي وزر تنبيه واتساب لكل شقة أو للكل (واحدة بعد الأخرى، لأن واتساب لا يسمح بإرسال تلقائي)، وتراجع الإيصالات (تأكيد/رفض)، وتفعّل/تُخفي رصيد الصندوق وتحصيل المشروع وجملة اليوم، وتضيف مشروعاً جديداً (صف في Items بنوع مشروع)، وتعدّل الإعلان. كل شيء يُقرأ من الشيت ويُكتب فيه، فأي تعديل في الشيت يظهر في اللوحة (تحديث تلقائي كل دقيقة أو بزر تحديث).

لو عندك شيت قديم (قبل النسخة العربية أو قبل هذه التحديثات):
1) الصق Code.gs الجديد في Apps Script واحفظ.
2) شغّل migrate مرة واحدة.
3) شغّل installTrigger مرة (يضيف النسخ الاحتياطي الأسبوعي) ثم protectSheets مرة.
4) Deploy ← Manage deployments ← ✏️ ← New version.
5) ارفع index.html وmaintenance.html وadmin.html الجديدة على GitHub (مع رابط الـ Web app).
6) انقل بيانات الدفع القديمة إلى وسيلة الدفع 1 و2 في Settings، واملأ رمز مسؤول الصيانة، ثم شغّل securityTest وراجع Execution log.
